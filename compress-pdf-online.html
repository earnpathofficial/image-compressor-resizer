Compress PDF Online for Free

ImageTools PDF Compressor helps reduce the size of PDF documents directly in your browser. It can be useful when a PDF is too large for email, online forms, uploads, or messaging applications.

Start with Basic compression for lighter processing, Balanced for a general-purpose result, or Strong when reducing file size is more important.

How it works

  1. Select your PDF.
  2. Choose a compression level.
  3. Tap Compress PDF.
  4. Download the resulting PDF.

Compression methods

Basic uses structural PDF optimization with qpdf. This is designed to reduce unnecessary PDF data while preserving the original PDF structure and content.

Balanced uses browser-based image compression with moderate settings to reduce PDF page image sizes while maintaining a balance between quality and file size.

Strong uses stronger browser-based image compression to prioritize a smaller file size.

Balanced and Strong may rasterize PDF pages. This can change selectable text and some original PDF structure because PDF pages may be converted into compressed images.

PDF structural optimization uses qpdf WebAssembly. qpdf is distributed under the Apache License 2.0. The browser-based compression uses PDF.js and pdf-lib.

Frequently Asked Questions

Is this PDF compressor free?

Yes. ImageTools PDF Compressor is free to use in your browser.

Are my PDF files uploaded?

No. The PDF is processed locally in your browser and is not uploaded to ImageTools servers.

Which compression level should I use?

Basic is suitable when preserving the original PDF structure is important. Balanced is designed for a compromise between file size and quality. Strong is intended for situations where reducing file size is the priority.
