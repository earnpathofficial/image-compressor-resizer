Compress PDF Online for Free

ImageTools PDF Compressor helps reduce the size of PDF documents directly in your browser. It can be useful when a PDF is too large for email, online forms, uploads, or messaging applications.

Start with Basic compression for lighter processing, Balanced for a general-purpose result, or Strong when reducing file size is more important.

How it works

  1. Select your PDF.
  2. Choose a compression level.
  3. Tap Compress PDF.
  4. Download the resulting PDF.

The compressor first attempts structural PDF optimization. If the selected compression level can produce a smaller browser-based version, ImageTools compares the results and keeps the smaller file.

PDF structural optimization uses qpdf WebAssembly. qpdf is distributed under the Apache License 2.0. The browser-based fallback uses PDF.js and pdf-lib.
