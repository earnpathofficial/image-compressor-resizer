Frequently Asked Questions

How do I make an image smaller than 200 KB?

Choose Target File Size, enter 200 KB and select JPG or WebP. The compressor will search for a suitable quality level.

Does target size guarantee the exact file size?

No. The result depends on the image, dimensions, format and browser. The tool aims to get the image at or below the requested target when practical.

Are my images uploaded?

No. Processing happens directly in your browser.

Can I compress multiple images?

Yes. You can select multiple images or drag multiple images into the upload area.

Which formats can I export?

You can export images as JPG, PNG or WebP.
