How to Compress an Image Online

  1. Tap Compress an Image.
  2. Select a JPG, PNG or WebP image from your device.
  3. Choose your preferred compression quality.
  4. For a specific file size, use Target File Size.
  5. Process the image and download the compressed result.

Why Compress Images?

Large image files can take longer to upload, download and share. Compressing an image can reduce its file size and make it easier to use on websites, social media, messaging apps and online forms.

ImageTools lets you compress images directly in your browser without requiring you to upload your original image to a server.

Supported Image Formats

  • JPG / JPEG
  • PNG
  • WebP

Choose a Compression Method

ImageTools provides several ways to reduce image size.

  • Quality Compression — choose a simple quality preset.
  • Target File Size — aim for a specific size such as 100 KB or 200 KB.
  • Resize — reduce image dimensions to help reduce file size.
  • Smart Resize — quickly resize to common image widths.
